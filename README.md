# React Annotator for Claude\n\nA Firefox extension for annotating React components with comments, then exporting for Claude Code.\n\n## Features\n- Click any element to add annotations\n- Visual comment icons on annotated elements\n- Automatic React component detection\n- Export all annotations in Claude-friendly format\n\n## Installation\n1. Open Firefox\n2. Go to about:debugging#/runtime/this-firefox\n3. Click 'Load Temporary Add-on'\n4. Select manifest.json
